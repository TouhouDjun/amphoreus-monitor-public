# 素材说明（重要）

开源版仓库**不包含**任何官方美术素材与音乐，原因见根目录 README 的「版权说明」。

程序本身对缺图做了兜底：找不到 `assets/立绘/<角色>.jpg` 时，
界面会显示「首字 + 未记录」的占位，功能（编年史、演算沙盘、个体档案）仍然完整可跑。
